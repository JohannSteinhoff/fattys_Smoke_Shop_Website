# Fatty's Smoke Shop — Website

A concept marketing website for **Fatty's Smoke Shop**, San Marcos, TX.

🔗 **Live site:** _add your GitHub Pages URL here after deploying_

## About

Single-page, fully responsive site built as a static `index.html` (no build step,
no dependencies). Dark theme with a gold accent. Designed as a sales/marketing
mockup for the shop.

- **Address:** 1330 Aquarena Springs Dr, Ste 105, San Marcos, TX 78666
- **Phone:** (512) 667-6413
- **Hours:** Mon–Sat 9 AM–12 AM · Sun 10 AM–11 PM
- **Established:** 2007

## Structure

```
index.html          # the entire website (HTML + CSS inline)
images/             # full-resolution source photos (JPG)
images/webp/        # web-optimized WebP versions used by the site
.nojekyll           # tells GitHub Pages to serve files as-is
```

## Run locally

Just open `index.html` in any browser — no server required.

## Deploy to GitHub Pages

1. Push this repo to GitHub.
2. Repo **Settings → Pages**.
3. Under **Build and deployment**, set **Source: Deploy from a branch**,
   **Branch: `main`** / folder **`/ (root)`**, then **Save**.
4. Your site goes live at `https://<username>.github.io/fattys_Smoke_Shop_Website/`
   within a minute or two.
